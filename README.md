# 客户项目资料管理系统

当前阶段：MVP 需求、数据设计和本地 Web 原型。

## 文件索引

- `app.py`  
  本地 Web 原型启动入口。

- `customer_m/`  
  后端模块包：`config.py` 配置和常量，`database.py` 数据库初始化和迁移，`services.py` 项目/文件业务逻辑，`server.py` HTTP 接口。

- `customer_m/modules/`  
  后端业务模块：客户与联系人、项目记录、基础下拉数据、生命周期辅助、目录管家、文件分类、文档解析、文件导入和目录扫描。

- `static/`  
  前端页面，包含新项目录入、项目列表、筛选和项目详情抽屉。

- `run_server.cmd`  
  Windows 启动脚本。

- `tools/version.cmd` / `tools/version.ps1`  
  Git 版本管理半自动脚本，支持查看状态、保存提交、创建功能分支和打版本标签。

- `VERSIONING.md`  
  版本管理规则和脚本使用说明。

- `ARCHITECTURE.md`  
  后端模块职责和后续拆分方向说明。

- `customer-project-management-requirements-v0.2.md`  
  当前主需求文档，方向为“新项目优先规范录入，老项目按需补录”。已补充“临时项目号 + 内部设备号”的双编号策略。

- `mvp-data-model-v0.2.md`  
  当前 MVP 数据模型说明。支持系统临时项目号、后补内部设备号、CNY/USD 币种和项目根目录配置。

- `mvp-sqlite-schema-v0.2.sql`  
  当前 SQLite 建表草案，已用内存 SQLite 验证语法通过。

- `new-project-entry-spec-v0.2.md`  
  当前新项目录入页面规格。允许创建项目时暂时没有内部设备号。

- `customer-project-management-requirements-v0.1.md`  
  原始需求讨论版本，保留作为历史记录。

- `mvp-data-model-v0.1.md`、`mvp-sqlite-schema-v0.1.sql`、`new-project-entry-spec-v0.1.md`  
  早期数据和页面规格，保留作为历史记录。

## 当前 MVP 方向

```text
新项目优先规范录入
老项目按需补录
历史目录后续批量索引
临时项目号先行，内部设备号后补
先建项目文件夹，再放资料并重新扫描
```

## 已确认配置

- 项目设备号允许英文字母、数字、横杠、下划线。
- 新项目早期可能没有内部设备号。
- 系统自动生成临时项目号。
- 常用币种为人民币和美元。
- 项目文件根目录为 `D:\01_CustomerProject`。
- 备份目录待定，倾向移动硬盘、NAS 或网盘同步目录。
- 第一阶段先做本地 Web 原型，后续封装为桌面软件。
- 当前文件文本提取支持 PDF、Word `.docx`、Excel `.xlsx`、TXT、CSV。
- 客户结构支持 `客户集团 → 客户公司/法人主体 → 工厂/站点 → 客户产品/生产线 → 项目/设备/夹具`。
- 项目需求来源和 `PO/采购主体` 可以分开记录。
- 客户产品/生产线会创建 `00_共享资料`，用于放置产品资料、生产线 Layout、客户通用规范等共用文件。
- 项目性质支持新设备、老设备改造、夹具/治具、备件/耗材、售后/服务、纯方案/报价等。
- 工厂/站点下固定分为 `01_独立项目` 和 `02_客户产品项目`；能归属客户产品的项目优先进入客户产品目录，`01_独立项目` 只作兜底。
- 项目内物理文件夹采用 5 类：`01_输入资料`、`02_报价与订单`、`03_方案与图纸`、`04_交付与验收`、`99_其他`。
- 项目列表支持点击表头排序；英文输入字段会自动首字母大写。

## 版本管理

建议使用 Git 管理代码版本，并把仓库上传到 GitHub；不要把本地数据库、客户资料文件夹或备份目录提交到仓库。

推荐提交内容：

```text
app.py
customer_m/
static/
*.md
*.sql
run_server.cmd
.gitignore
```

不推荐提交内容：

```text
data/customer_projects.db
D:\01_CustomerProject
客户报价、PO、图纸、模型等真实项目资料
```

## 推荐试用流程

```text
创建新项目
→ 系统生成项目文件夹
→ 在项目详情中点击“打开项目文件夹”
→ 把邮件、微信、桌面上的散乱资料放进去
→ 在项目详情顶部点击“扫描项目文件”
→ 在项目详情中检查文件索引
```

## 本地运行

当前原型服务已启动：

```text
http://127.0.0.1:8765
```

手动启动方式：

```bat
run_server.cmd
```

或使用 bundled Python：

```bat
C:\Users\Lenovo\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe app.py
```

运行后会在本工作区生成本地数据库：

```text
data\customer_projects.db
```
